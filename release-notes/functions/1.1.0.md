## Para o usuário

### Headline
- Notificações internas quando alguém chega no jogo

### Destaques
- icon=notifications | Chegada avisada | Quando um jogador faz check-in, os outros confirmados recebem uma notificação interna.
- icon=security | Sem duplicação | As notificações usam identificador determinístico para evitar spam em retries.

## Técnico

### Added
- `checkInToGame` salva notificações `checkin` para outros confirmados após check-in novo.
- Tipo `NotificationType.CHECKIN` para padronizar o payload salvo em `notifications`.

### Security
- Notificação roda server-side e best-effort, sem permitir escrita direta de presença pelo cliente.
