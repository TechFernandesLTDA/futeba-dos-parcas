## Para o usuário

### Headline
- Backend seguro para reputação pós-jogo

### Destaques
- icon=security | Agregação server-side | A reputação do perfil é recalculada no backend, não pelo cliente.
- icon=sports_soccer | Só participantes avaliam | A Function valida jogo finalizado e confirmações dos dois jogadores.
- icon=repeat | Avaliação idempotente | Um jogador atualiza a própria avaliação para o mesmo parça/jogo em vez de duplicar.

## Técnico

### Added
- Callable `submitPostGameReputation` com App Check, perfil completo e rate limit.
- Collection `post_game_reputation` com documento `{gameId}_{reviewerId}_{targetUserId}`.
- Recalculo transacional de `reputation_overall_avg`, critérios e `reputation_reviews_count` em `users/{targetUserId}`.

### Security
- Firestore Rules bloqueiam escrita direta em `post_game_reputation` e tornam `reputation_*` server-only em `users`.
