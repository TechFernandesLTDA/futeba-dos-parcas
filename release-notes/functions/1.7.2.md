## Para o usuário

### Headline

- A Liga agora consegue listar jogadores reais validados sem depender de expor dados privados do cadastro.

### Correções

- Usuarios pesquisaveis aparecem na Liga/XP global mesmo sem participacao em temporada.
- Donos de grupo recebem uma lista publica segura para convidar jogadores.

## Técnico

### Added

- Nova callable `getLeaguePlayers` retorna somente campos publicos e stats de Liga.

### Fixed

- Evita que regras de privacidade de `users/{uid}` bloqueiem a tela de Liga quando os docs contem PII.
