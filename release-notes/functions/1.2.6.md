## Para o usuário

### Headline
- CRM admin agora retorna dados comerciais das quadras do dono

### Melhorias
- A busca admin de usuários passa a incluir quadras vinculadas, mensalidade agregada, gerentes e status comercial por dono.
- A ficha comercial no web deixa de depender de dados mockados ou varredura limitada no navegador.

## Técnico

### Changed
- `searchAdminUsers` retorna `ownerLocations`, contatos básicos, timestamps de atualização e agregados financeiros por owner.
- A versão Functions foi atualizada para `1.2.6`.

### Security
- A callable continua admin-only, com App Check em produção, rate limit dedicado e auditoria habilitada.
