## Para o usuário

### Headline

- Vídeos enviados ao Mural agora encontram o transcodificador seguro dentro da própria Function de produção.

### Correções

- O empacotamento inclui o FFmpeg Linux pinado mesmo quando o deploy parte de um Mac.
- O deploy falha antes da publicação se o arquivo ou o binário não corresponder aos hashes aprovados.
- A primeira tentativa de vídeo deixa de depender de uma etapa de build que a plataforma não executa.

## Técnico

### Fixed

- O predeploy executa `install:ffmpeg` antes de lint e build e inclui `vendor/ffmpeg/ffmpeg` com modo executável no source bundle.
- Hosts macOS validam SHA-256 do archive e do ELF Linux; o runtime Linux mantém a validação executável da versão 8.1.2.
- Testes protegem o contrato cross-platform e a ordem obrigatória do predeploy.
