## Para o usuário

### Headline
- Busca admin de usuários ficou preparada para CRM comercial

### Melhorias
- Administradores podem consultar usuários e donos de quadra com filtros comerciais sem depender de uma página já carregada no navegador.
- Resumos de quadras por dono passam a ser calculados no backend para reduzir falsos negativos no CRM.

## Técnico

### Added
- Callable admin-only `searchAdminUsers` com paginação, busca textual e filtros por role/status comercial.
- Agregação server-side de `locations` por owner para total de quadras, publicadas, pendentes, suspensas/vencidas e cadastro comercial incompleto.

### Security
- A callable exige autenticação, role `ADMIN`, App Check fora do emulador e rate limit dedicado.
