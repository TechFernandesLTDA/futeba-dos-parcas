## Para o usuário

### Headline
- Criar jogo ficou mais didático no Android

### Correções
- Adiciona placeholders e teclado numérico/decimal nos campos de preço e jogadores.
- Mostra exemplos e faixas aceitas para preço, jogadores, goleiros, times e recorrência.
- Deixa mais claro quando usar `0` em jogos sem cobrança.

## Técnico

### Fixed
- `CreateGameScreen` usa `KeyboardOptions` adequadas para campos numéricos.
- `NumberStepper` passa a exibir helper text com os limites aceitos.
- Recursos de string do fluxo de Criar Jogo foram atualizados para documentar ranges e exemplos.
