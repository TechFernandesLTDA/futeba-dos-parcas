## Para o usuário

### Headline

- Vídeos do Mural continuam publicáveis mesmo quando o navegador não consegue gerar a pré-visualização.

### Melhorias

- A pré-visualização de vídeos usa um ciclo de vida seguro para o arquivo local, evitando que o navegador revogue o conteúdo antes da reprodução.
- Quando a pré-visualização falhar, o Mural informa o problema sem bloquear a publicação.

### Correções

- Corrigido o erro “Não foi possível preparar este vídeo para visualização” ao anexar vídeos aos posts do grupo.

## Técnico

### Fixed

- Object URLs de vídeos MP4 são criadas e revogadas no ciclo de vida do arquivo selecionado, com cobertura para React Strict Mode.
- Falhas do elemento `<video>` agora exibem estado não bloqueante e preservam o envio do arquivo original.
- Adicionado teste de regressão para publicar vídeo após falha da pré-visualização.
