## Para o usuário

### Headline

- Painel do dono de quadra passa a usar estatísticas comerciais consolidadas.

### Melhorias

- O dashboard do dono deixa de buscar jogos em massa no navegador para calcular métricas de agenda.
- O app reconhece os novos agregados de preço, campos ativos, tipos de quadra, avaliações e jogos da quadra.

## Técnico

### Changed

- `FieldOwnerDashboardScreen` passa a consumir agregados denormalizados em `locations`.
- Tipos web de `Location` agora expõem agregados comerciais mantidos pelo backend.
- Modelo KMP de `Location` foi alinhado com os novos campos denormalizados.
