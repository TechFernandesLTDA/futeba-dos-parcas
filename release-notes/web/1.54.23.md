## Para o usuário

### Headline

- As telas no celular agora exibem um único cabeçalho, com mais espaço e navegação mais clara.

### Correções

- Rotas secundárias não repetem mais o título nem o botão de voltar.
- Leitores de tela anunciam corretamente o Guia do Jogador e o check-in por QR code.
- A tela de evolução mantém sua grade responsiva sem avisos de compatibilidade.

## Técnico

### Changed

- O shell mobile ganhou um mecanismo explícito para telas que já possuem cabeçalho próprio.
- O anúncio de rotas cobre `/guide` e deep links `/checkin/:gameId/:token`.
- `EvolutionScreen` usa a API Grid2 compatível com a versão atual do MUI.
- Build, lint, testes focados e a suíte completa web foram validados.
