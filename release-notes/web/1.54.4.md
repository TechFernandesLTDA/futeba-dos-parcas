## Para o usuário

### Headline

- O login com Google agora funciona no endereço oficial futebadosparcas.com.br.

### Correções

- O fluxo de autenticação deixa de depender do domínio técnico do Firebase ao abrir pelo novo endereço oficial.
- O domínio oficial e o callback de autenticação foram autorizados no cliente OAuth do Google.

## Técnico

### Fixed

- `VITE_FIREBASE_AUTH_DOMAIN` agora usa `futebadosparcas.com.br`, mantendo o iframe e o handler de autenticação na mesma origem do aplicativo.
- O cliente OAuth Web autoriza `https://futebadosparcas.com.br` e `https://futebadosparcas.com.br/__/auth/handler`.
