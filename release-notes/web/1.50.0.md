## Para o usuário

### Headline

- Convites agora podem sair direto da tela de Liga.

### Destaques

- icon=group | Convidar pela Liga | Donos e administradores conseguem chamar jogadores visíveis no ranking para grupos ou jogos futuros que gerenciam.
- icon=soccer | Convite para jogo | Convites para jogo criam presença pendente, convocação e notificação acionável.

### Melhorias

- A Liga mostra a ação de convite apenas para outros jogadores pesquisáveis e quando o usuário tem grupo ou jogo elegível.
- O diálogo permite escolher entre grupo ou jogo antes de enviar.
- O envio bloqueia duplicidade de convite pendente para o mesmo grupo e presença/convite já existente no mesmo jogo.
- Notificações de convite de grupo no web passam a aceitar ou recusar o convite usando o ID salvo pelo backend.

## Técnico

### Added

- `useLeagueInvites` centraliza opções de grupo/jogo e escrita de `group_invites`, `game_summons`, `confirmations` e `notifications`.
- `LeagueScreen` ganhou botão e diálogo de convite no layout mobile e desktop.

### Changed

- Notificações web interpretam `action=group_invite/<id>` para responder convites diretos de grupo.
