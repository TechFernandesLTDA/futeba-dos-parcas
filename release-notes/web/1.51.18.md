## Para o usuário

### Headline

- Melhoramos a instalação do web app no celular.

### Melhorias

- A tela de login e a home agora mostram uma chamada clara para usar o Futeba como app.
- No Android e em navegadores compatíveis, o botão de instalar abre o prompt nativo do navegador.
- No iPhone, a tela orienta o fluxo correto pelo Safari para adicionar o app à Tela de Início.

## Técnico

### Added

- Adicionado hook `usePwaInstall` para capturar `beforeinstallprompt`, detectar standalone e diferenciar iOS, Android e desktop.
- Adicionado ícone Apple Touch 180x180 e metadados de instalação no manifest e no HTML.

### Fixed

- Service worker atualizado para `futeba-v9`, cacheando o novo ícone PWA e invalidando caches antigos após o deploy.
