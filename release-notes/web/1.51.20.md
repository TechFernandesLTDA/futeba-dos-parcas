## Para o usuário

### Headline

- O web app ficou mais resistente quando o navegador mobile prende cache ou autenticação no carregamento.

### Correções

- Corrigido um caso em que navegadores mobile com estado local travado, como Vivaldi, podiam ficar presos na tela de carregamento.
- O service worker agora força uma troca de cache para remover arquivos antigos do PWA no próximo acesso.

## Técnico

### Changed

- Adicionado watchdog no `AuthProvider` para continuar com o estado atual se o observador inicial do Firebase Auth não responder.
- Atualizado o cache do service worker para `futeba-v10`.
