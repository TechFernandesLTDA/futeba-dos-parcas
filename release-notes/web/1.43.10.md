## Para o usuário

### Headline
- Gestão segura de donos e gerentes de quadras

### Melhorias
- Administradores podem transferir o dono de uma quadra pela tela de gerenciamento.
- Donos de quadra e administradores podem criar convites de gerente sem liberar acesso imediato.
- Gerentes atuais podem ser removidos com registro de motivo interno para auditoria.
- A tela de detalhe da quadra agora mostra uma central operacional para admin/dono com status comercial, mensalidade, equipe, fotos, comodidades, campos e preços.
- O menu "Gerenciar Usuários" fica consistente para administradores mesmo quando o documento público do usuário ainda não refletiu a custom claim.

## Técnico

### Added
- `ManageLocationsScreen` ganhou o painel "Dono e gerentes" para transferência administrativa e convites de managers.
- `LocationDetailScreen` passou a carregar campos e fotos da quadra para uma visão unificada de visualização e edição.
- Cliente web passou a consumir as callables `assignLocationOwner`, `inviteLocationManager`, `acceptLocationManagerInvite` e `removeLocationManager`.

### Security
- A UI deixa claro que managers não podem publicar, cobrar, alterar dono ou mensalidade.
- `AuthContext` aplica a role efetiva das custom claims quando disponível, evitando perda temporária de menus administrativos.
