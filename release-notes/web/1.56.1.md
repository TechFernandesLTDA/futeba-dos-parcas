## Para o usuário

### Headline

- A lista de confirmação dos jogos volta a identificar os membros pelo nome.

### Correções

- Convites automáticos de membros do grupo não aparecem mais repetidos como “Membro” quando o nome não está duplicado no cadastro interno do grupo.
- O nome agora é obtido pela projeção autorizada dos participantes do grupo antes de criar a confirmação.

## Técnico

### Fixed

- `useAutoInviteMembers` hidrata nomes ausentes ou genéricos com `getLeaguePlayers` limitado ao grupo.
- `getUsersByIds` aceita `groupId` para incluir membros autorizados que não estão no diretório público global.
- Adicionada cobertura de regressão para membro com placeholder no documento do grupo.
