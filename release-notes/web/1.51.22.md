## Para o usuário

### Headline

- O XP e o nivel exibidos na web passam a acompanhar os logs reais de producao.

### Correções

- A tela Rumo ao Estrelato mostra XP ganho e nivel apos cada evento usando os registros atuais do historico de XP.
- Rankings, perfil, detalhes de jogador, confronto direto e pos-jogo deixam de transformar nivel 0 em nivel 1 artificial.
- A jornada de nivel passa a atualizar em tempo real quando um novo XP log e gravado.

## Técnico

### Fixed

- Adiciona normalizador `xpAccounting` para aliases `xp_earned`, `level_after`, `experience_points` e legados.
- Remove fallbacks `|| 1` em leituras de nivel e usa a tabela canonica para derivar nivel por XP.
- Cobre regressao para preservar nivel 0 e ler logs de XP atuais.
