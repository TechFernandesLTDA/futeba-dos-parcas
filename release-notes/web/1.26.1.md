## Para o usuário

### Headline
- Navegação mais confortável e changelog em dia

### Destaques
- icon=checklist | Páginas começam no topo | Ao trocar de tela, o conteúdo inicial aparece alinhado sem precisar rolar um pouquinho.
- icon=devices | Mobile e desktop mais estáveis | Ajustes de layout reduzem quebras de texto e scroll lateral em resoluções pequenas e grandes.
- icon=stars | Novidades atualizadas | A tela de changelog agora reflete as melhorias recentes publicadas na web.

### Novidades
- Nova entrada de changelog para a versão web mais recente.

### Melhorias
- Navegação entre abas e páginas agora considera a aba atual, para não reaproveitar a rolagem de outra tela.
- Foco de acessibilidade na troca de página não desloca mais o conteúdo para baixo da topbar.
- Login, cadastro e recuperação de senha ganharam ajustes finos para telas estreitas.

### Correções
- Corrigido o comportamento em que algumas páginas abriam levemente roladas para baixo.
- Corrigidos casos em que botões e links podiam quebrar de forma apertada no menor breakpoint mobile.

## Técnico

### Changed
- `useScrollRestoration` agora chaveia por `pathname + search`, rola para o topo em navegações novas e restaura posição apenas em navegação `POP`.
- `useFocusOnNavigate` usa `focus({ preventScroll: true })` para preservar o alinhamento visual após troca de rota.
- Componentes de auth, containers e topbar mobile receberam proteções de layout responsivo.

### Fixed
- Scroll inicial de páginas e abas web ajustado para não ficar escondido sob a topbar.
- Bundle de release notes web atualizado para refletir as mudanças recentes.
