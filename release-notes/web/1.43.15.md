## Para o usuário

### Headline
- Donos de quadra agora têm onboarding comercial controlado

### Melhorias
- Usuários podem solicitar aprovação para cadastrar quadras pela nova tela "Cadastrar minha quadra".
- A tela de Configurações ganhou entrada para iniciar ou acompanhar o onboarding comercial.
- Admins passam a revisar o onboarding pela ficha comercial do usuário, com checklist obrigatório antes da aprovação.
- A aprovação promove o usuário a dono de quadra; rejeição e suspensão passam a exigir um motivo.

## Técnico

### Added
- Rota web `/owner/onboarding` para solicitação de dono de quadra.
- Revisão admin integrada ao `UserManagementScreen`.
- A versão web foi atualizada para `1.43.15`.
