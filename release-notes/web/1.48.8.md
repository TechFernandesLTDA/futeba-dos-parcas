## Para o usuário

### Headline

- A criação de jogos agora exige um grupo formado.

### Destaques

- icon=groups | Grupo obrigatório | Para marcar jogo, o organizador precisa ser dono de um grupo com pelo menos 5 membros.

### Correções

- A tela de criar jogo passa a listar somente grupos próprios com 5 membros ou mais.
- Usuários sem grupo elegível recebem uma mensagem clara antes de tentar criar o jogo.
- A criação rápida por template segue a mesma regra de grupo qualificado.

## Técnico

### Fixed

- `CreateGameScreen` remove a opção de criar jogo sem grupo e filtra grupos inelegíveis.
- `useCreateGame` valida o grupo antes de gravar em `games`.
- `firestore.rules` rejeita criação direta de jogo sem `group_id`, com grupo de outro dono, inativo/deletado ou com `member_count < 5`.
