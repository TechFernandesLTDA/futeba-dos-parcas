## Para o usuário

### Headline
- Destaques pós-jogo para compartilhar a resenha

### Destaques
- icon=auto_awesome | Card pós-jogo | Partidas finalizadas agora mostram MVP, melhor dupla e lance marcante em um card compartilhável.
- icon=groups | Melhor dupla | O app combina gols, assistências e defesas já registradas para sugerir a dupla de maior impacto.
- icon=share | Compartilhe a memória | O card pode ser compartilhado pela Web Share API ou copiado quando o navegador não suporta compartilhamento nativo.

### Novidades
- Novo painel "Destaques pós-jogo" no detalhe de partidas finalizadas.
- Card compartilhável com placar, MVP e melhor dupla do jogo.
- Lance marcante gerado a partir das estatísticas existentes da partida.

### Melhorias
- Estados de carregamento, vazio e erro preparados para o fluxo de destaques pós-jogo.
- Fallback para jogos sem estatísticas ao usar jogadores confirmados no resumo.

## Técnico

### Added
- Utilitário `buildPostGameHighlights` com heurística testável para MVP, melhor dupla e lance marcante.
- Componente `PostGameHighlightsPanel` integrado ao `GameDetailScreen`.
- Testes unitários para cálculo e texto compartilhável dos destaques pós-jogo.
