## Para o usuário

### Headline
- Admin de usuários agora busca donos de quadra sem falso negativo

### Melhorias
- A tela de Gerenciar Usuários passa a buscar no servidor por nome, email, UID e role.
- Filtros comerciais de donos de quadra deixam claro quando há quadras, publicações e pendências.
- Estados de carregamento, vazio e erro foram ajustados para buscas server-side.

## Técnico

### Changed
- `UserManagementScreen` deixa de depender apenas do primeiro lote local de 50 usuários para busca e filtros.
- Integração web adicionada para a callable `searchAdminUsers`.
- A versão web foi atualizada para `1.43.13`.
