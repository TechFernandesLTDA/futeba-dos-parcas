## Para o usuário

### Headline
- Reputação pós-jogo no perfil dos parças

### Destaques
- icon=handshake | Avaliação leve pós-jogo | Após partidas finalizadas, jogadores confirmados podem avaliar pontualidade, respeito e compromisso.
- icon=shield | Perfil com reputação | O perfil agora mostra média geral, critérios e quantidade de avaliações recebidas.
- icon=task_alt | Atualização transparente | Cada jogador pode revisar uma avaliação enviada para o mesmo parça naquele jogo.

### Novidades
- Novo painel "Reputação pós-jogo" no detalhe de partidas finalizadas.
- Novo card "Reputação dos parças" no perfil do jogador.
- Estados de carregamento, erro e vazio para o fluxo de reputação.

## Técnico

### Added
- Hook web `usePostGameReputation` para carregar avaliações enviadas e chamar a Function server-side.
- Componente `PostGameReputationPanel` integrado ao `GameDetailScreen`.
- Agregados `reputation_*` exibidos no `ProfileScreen`.

### Security
- Cliente não escreve agregados de reputação diretamente; a UI chama `submitPostGameReputation`.
