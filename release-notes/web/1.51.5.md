## Para o usuário

### Headline

- A tela de gerenciamento de usuarios ficou mais legivel no celular.

### Correções

- A lista de usuarios no admin agora evita sobreposicao entre avatar, nome, email, badges e botoes de acao.
- Contas provaveis de QA/teste ficam sinalizadas visualmente, sem afetar usuarios reais validados.
- Emails longos e nomes grandes passam a quebrar linha corretamente no mobile.

## Técnico

### Changed

- `UserManagementScreen` passa a usar uma grade explicita no layout mobile da lista.
- A tela exibe o chip `QA/teste` para contas com padroes claros de teste, como dominio `@futeba.test`.

### Fixed

- Corrige overflow visual na lista mobile de usuarios administrativos.
