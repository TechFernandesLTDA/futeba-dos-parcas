## Para o usuário

### Headline
- Web orienta melhor quando uma operação administrativa fica temporariamente indisponível

### Melhorias
- A tela de gerenciamento de usuários agora mostra no alerta e no toast a mesma mensagem contextual retornada pelo tratamento central de Cloud Functions.
- Mensagens temporárias de indisponibilidade orientam recarregar a página e tentar novamente, reduzindo confusão durante rollouts ou instabilidades breves.

## Técnico

### Changed
- `UserManagementScreen` reutiliza a mensagem calculada por `getFunctionsErrorMessage` no toast.
- `getFunctionsErrorMessage` recebeu mensagens mais acionáveis para `failed-precondition` e `unavailable`.
- Cobertura unitária adicionada para erros de Cloud Functions no mapper Firebase.
- A versão web foi atualizada para `1.43.19`.
