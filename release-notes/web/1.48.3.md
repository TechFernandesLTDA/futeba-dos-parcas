## Para o usuário

### Headline

- A tela de desafios do grupo voltou a carregar corretamente para grupos normais.

### Destaques

- icon=sports_soccer | Desafios no grupo | O botão de desafiar agora reconhece o grupo aberto mesmo quando ele não vem da lista de grupos oficiais.
- icon=bolt | Carregamento ajustado | As consultas de desafios ganharam os índices necessários para listar enviados e recebidos por data.

### Melhorias

- A tela de desafios passa a usar o documento real do grupo como fonte do nome do desafiante.
- O botão de criar desafio só fica ativo quando o grupo atual e a lista de adversários estão disponíveis.

## Técnico

### Fixed

- `GroupChallengesScreen` deixou de depender exclusivamente de `official-groups` para resolver o grupo atual.
- Firestore indexes adicionados para `group-challenges` por `challenged_group_id/created_at` e `challenger_group_id/created_at`.
