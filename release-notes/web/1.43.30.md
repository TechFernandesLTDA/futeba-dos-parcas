## Para o usuário

### Headline

- Admin agora configura a conta comercial agregada do dono de quadra.

### Melhorias

- A ficha comercial de usuários ganhou criação e edição de conta comercial por dono de quadra.
- O admin pode definir status, modelo de cobrança, plano, ciclo, mensalidade final, vencimento, vigência, contato financeiro e observações.
- A conta comercial permite vincular as quadras do dono ao contrato único, mantendo o fluxo auditado pelas Cloud Functions.

## Técnico

### Added

- Formulário web em `/admin/users` usando a callable `upsertVenueAccount`.
- Teste cobrindo o salvamento da conta comercial agregada.

### Changed

- O gerenciamento de usuários deixa de apenas exibir `venue_accounts` e passa a operar a configuração comercial centralizada.
