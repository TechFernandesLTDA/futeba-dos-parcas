## Para o usuário

### Headline
- Admin de usuários ganhou ficha comercial de donos de quadra

### Melhorias
- A tela de Gerenciar Usuários agora mostra uma ficha comercial completa ao abrir um usuário.
- Donos de quadra exibem receita mensal agregada, quadras vinculadas, status de publicação, status de mensalidade, gerentes e pendências.
- Administradores podem navegar da ficha para visualizar ou editar cada quadra relacionada.
- Rebaixar um dono de quadra com cadastros vinculados exige confirmação reforçada.
- Alterações em lote bloqueiam rebaixamento para Player quando há donos com quadras vinculadas.

## Técnico

### Changed
- `UserManagementScreen` passa a renderizar o detalhe comercial usando dados retornados por `searchAdminUsers`.
- A versão web foi atualizada para `1.43.14`.
