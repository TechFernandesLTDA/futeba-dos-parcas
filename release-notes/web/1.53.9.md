## Para o usuário

### Headline

- **Criar jogo funcionando novamente!** O erro ao criar jogo a partir do grupo foi corrigido — um campo interno estava sendo recusado pelas regras de segurança.

### Correções

- A criação de jogo no web parou de enviar um campo interno que era bloqueado pelas regras de segurança.
- A política de segurança do site já libera os novos endereços de armazenamento, preparando o terreno para os envios de mídia.
- Os jogos recorrentes agora herdam gênero, nome e co-organizadores do jogo original.
- Android: criar e editar jogo não enviam mais campos controlados pelo servidor.
- Android: editar um jogo agora atualiza apenas os campos alterados, sem apagar dados controlados pelo servidor.
- Android: ao criar o próximo jogo de uma recorrência, os dados controlados pelo servidor são zerados.
