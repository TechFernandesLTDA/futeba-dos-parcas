## Para o usuário

### Headline

- Ficou mais fácil avisar quando uma tela quebra.

### Destaques

- icon=bug | Reportar erro pela própria falha | A tela global de erro agora permite enviar um relatório direto para a fila interna de feedback, com o código da falha e a tela onde aconteceu.

### Melhorias

- Usuários autenticados podem registrar falhas visíveis sem precisar copiar detalhes manualmente.
- O envio também funciona para contas autenticadas que não têm e-mail no token.
- O relatório inclui rota, URL, código do erro, navegador, versão do app e contexto técnico limitado para acelerar a triagem.
- Quando o envio automático não é possível, a tela informa o próximo passo sem esconder os botões de recarregar, voltar ao início ou copiar detalhes.

## Técnico

### Added

- `ErrorBoundary` ganhou ação de reporte para criar documentos em `user_feedback` como `bug/high`.
- `errorFeedbackReporter` centraliza o payload seguro para feedback originado por crash.
- Firestore Rules de `user_feedback` aceitam `user_email` vazio para usuários autenticados sem e-mail no token, sem permitir spoofing de e-mail.
- Testes cobrem envio autenticado e orientação de login no fallback global de erro.
