## Para o usuário

### Headline

- O envio da foto do grupo foi corrigido para não falhar por permissão do Firebase Storage.

### Correções

- A criação e a edição do grupo agora enviam o logo por um caminho de Storage próprio do usuário autenticado.
- Isso remove a dependência de uma validação instável do Storage que consultava permissões do grupo no Firestore durante o upload.

## Técnico

### Fixed

- Move o upload web de logos de grupo para `users/{uid}/group-logos/{groupId}/logo.{ext}`.
- Adiciona regra de Storage específica para esse path, validando dono do diretório, tipo de imagem e tamanho.
- Mantém `groups/{groupId}.photo_url` como fonte exibida para os demais usuários.
