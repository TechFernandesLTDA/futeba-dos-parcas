## Para o usuário

### Headline
- Conciliação manual de mensalidades ficou mais completa

### Melhorias
- Donos de quadra agora visualizam pagamentos e comprovantes enviados, incluindo pendências, aprovações e rejeições.
- Administradores podem registrar um pagamento com comprovante e aprovar imediatamente pela tela de quadras.
- A data do pagamento passa a ser informada no envio do comprovante para melhorar o histórico financeiro.
- A tela de comprovantes diferencia status aprovado, rejeitado e em revisão.

## Técnico

### Changed
- `ManageLocationsScreen` passou a listar os últimos pagamentos da subcoleção `subscription_payments` para owner/admin.
- O fluxo admin usa `submitLocationSubscriptionReceipt` seguido de `reviewLocationSubscriptionReceipt` para registrar e aprovar manualmente mantendo auditoria.
- A versão web foi atualizada para `1.43.12`.
