## Para o usuário

### Headline
- Admin ganha painel financeiro de quadras monetizadas

### Melhorias
- A tela de gerenciamento de quadras mostra MRR previsto, recebido no período, vencido, trial e suspenso.
- Admins conseguem filtrar quadras por vencimento, cidade, dono, status comercial, publicação, tipo e comodidades.
- Cada quadra passa a exibir recebido, saldo aberto e comprovantes pendentes do período selecionado.
- Admins podem exportar o resumo financeiro do período em CSV.
- O resumo financeiro vem do backend, evitando cálculo sensível e limitado no client.

## Técnico

### Added
- Integração web com `getAdminLocationBillingSummary`.
- Cards administrativos alimentados por resumo financeiro server-side.
- Filtros comerciais adicionais para vencimento, cidade e UID do dono.
- Exportação CSV admin baseada nas linhas retornadas pelo backend.
- A versão web foi atualizada para `1.43.17`.
