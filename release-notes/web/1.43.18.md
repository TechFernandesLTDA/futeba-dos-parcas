## Para o usuário

### Headline
- Web mostra ciclo financeiro atual das quadras

### Melhorias
- Admins passam a ver status do ciclo mensal, saldo atual, vencimento e data de suspensao no gerenciamento de quadras.
- Donos de quadra recebem alerta quando existe mensalidade em aberto no ciclo atual.
- A tela deixa claro que o saldo vem do backend, reduzindo divergencia entre pagamento, status e exibicao.

## Técnico

### Added
- Novos campos tipados em `AdminLocationBillingSummaryRow` para ciclo atual.
- Chips administrativos para ciclo, vencimento e suspensao.
- Alerta financeiro no painel do dono de quadra baseado em `current_billing_open_balance_cents`.
- A versao web foi atualizada para `1.43.18`.
