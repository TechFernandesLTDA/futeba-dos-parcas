## Para o usuário

### Headline

- Corrigimos a abertura do web mobile em celulares com cache antigo.

### Correções

- O app instalado ou aberto no celular agora limpa caches antigos quando encontra um bundle que nao existe mais.
- A versao web forca atualizacao do service worker para evitar tela em branco causada por arquivos antigos do app.
- Rotas mobile continuam abrindo normalmente e redirecionam para login quando o usuario nao esta autenticado.

## Técnico

### Fixed

- Hosting passa a responder um fallback JavaScript para chunks antigos em `/assets/**`, evitando servir `index.html` como se fosse modulo JS.
- O fallback remove service workers/caches antigos e recarrega a pagina atual com cache bust.
- `sw.js` foi atualizado para `futeba-v8`, purgando caches PWA anteriores na proxima ativacao.
