## Para o usuário

### Headline
- Controle comercial de quadras começou a chegar ao admin

### Melhorias
- Quadras agora carregam status de publicação e mensalidade na gestão administrativa.
- Admins passam a ter ações rápidas para publicar, suspender, marcar mensalidade em dia ou vencida.
- A seleção pública de quadras passa a respeitar elegibilidade comercial, mantendo compatibilidade com quadras verificadas antigas.

## Técnico

### Added
- Contrato web para status de publicação, assinatura e mensalidade de quadras.
- Documentação `docs/VENUE_MONETIZATION.md` para o modelo de monetização.

### Changed
- `useLocations` e o mapa público filtram quadras comercialmente indisponíveis.
- Cadastro completo e criação rápida iniciam quadras como `PENDING_REVIEW` e `TRIAL`.

### Security
- Campos comerciais passam a depender das novas operações administrativas protegidas no backend.
