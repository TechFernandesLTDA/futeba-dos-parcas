# Prompts de Geração de Imagens — Badges Lendas do Futebol (Níveis 11-20)

> Use estes prompts em DALL-E 3, Midjourney, Stable Diffusion ou similar.
> Após gerar, redimensione para **1536x1024px PNG RGBA** com fundo transparente.

---

## Especificações técnicas

| Propriedade | Valor |
|-------------|-------|
| Formato | PNG RGBA (transparente) |
| Dimensão | 1536 x 1024 pixels |
| Fundo | Transparente (sem background) |
| Estilo | Cartoon 2D, cores vibrantes, traço expressivo, engraçadinho |
| Layout | Retrato cartoon da lenda em destaque + número do nível em fonte bold |
| Nome dos arquivos | `level_11.png` … `level_20.png` (web) / `ic_level_badge_11.png` … `ic_level_badge_20.png` (Android) |

---

## Instruções de estilo (comum a todos)

```
Ilustração cartoon 2D estilo "chibi futebol", cores vibrantes, traço expressivo
e divertido. O personagem deve ocupar ~60% da imagem, centralizado, com expressão
caricata e pose de comemoração característica. Sem background — fundo 100%
transparente (PNG alpha). O número do nível deve aparecer no canto superior
esquerdo em fonte bold grande, estilo placa de camisa de futebol. Traço limpo
e vetorial, sem degradê, sem sombras complexas.
```
